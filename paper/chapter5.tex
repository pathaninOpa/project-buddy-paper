
\chapter{CONCLUSION}
{ 
	\setlength{\leftskip}{1cm}
	\setlength{\parindent}{2.5em}
	This project presents an interactive companion designed for the elders and the caretakers. Combining an LLMs model, sentiment analysis model, caretaker’s application, and care receiver’s application. This system aims to make communication between caretakers and elders easier, especially for elders who struggle with digital devices. Integrating voice activated functions and LLMs on the elder’s application, the system reduces the technological barriers and allows a natural interaction between “Buddy” and the elders. On the caretakers side, an elder's emotional state insight is provided, so that caretakers can monitor their beloved emotion, and provide help when needed. Combined with the remainder function, and call feature using ZegoCloud which allows the caretaker to make sure that the elder remembers the important task that they need to do video, and a remote connection. 
	\par
}

{ 
	\setlength{\leftskip}{1cm}
	\setlength{\parindent}{2.5em}
	The objectives of this project were all effectively accomplished with a satisfactory core performance, evaluated by 5 performance dimensions. Speech to text performance Metric evaluated by Word Error Rate (WER) and Character Error Rate (CER), which result in surpassing the standard for both word error rate and character error rate. Emotion recognition performance was measured by evaluating against a manually labeled, resulting in 0.93 precision, 0.93 recall and 0.93. Demonstrating that it is quite successful at accurately classifying emotions while reducing false positives and false negatives. Dialog generation quality was determined based on two points which includes LLM as judge evaluation results, and a survey score from human evaluation, and the both results are positive. For telecommunication systems, the video call function utilizes ZegoCloud to establish peer-to-peer connection, evaluated by the connection success rate, average latency, and call stability, which result in a very satisfactory module. Last but not least, the satisfaction of user, measured by conducting a survey with 20 participants, overall satisfaction are generally positive reception among the test group, on the other hand, the accuracy of response is lower than the average, as same as it's respond speed, which also get a lower than average score as well. From the qualitative feedback. it represent that this app strong point is an ability to provide an answer on daily life and general health topics. In contrast to it's ability to handle a complex question or specific domain knowledge.
	\par
}

{ 
	\setlength{\leftskip}{1cm}
	\setlength{\parindent}{2.5em}
	Overall, the system shows a practical tool that simplifies the technology for elders, and improves emotional awareness in elder care. The combination of this system, brings out the potential of assistive technology to support the aging population, and enhance the quality of remote caregiving.
